# 规则索引完整性规则

## 核心原则
AGENTS.md规则索引必须与.trae/rules/目录完全一致，确保所有规则被正确索引和引用。

## 强制规则
1. AGENTS.md规则索引数量必须与.trae/rules/目录文件数量一致
2. AGENTS.md规则索引必须包含所有规则文件
3. 新增规则文件时，必须同步更新AGENTS.md索引
4. 规则文件名变更时，必须同步更新AGENTS.md索引引用

## 索引格式
```
## 规则文件索引（{N}条）
以下规则文件位于 .trae/rules/ 目录，alwaysApply: true，每次对话自动注入：
0. {文件名} — {规则说明} ✅
1. {文件名} — {规则说明} ✅
...
```

## 一致性校验
每次修改规则文件时，必须校验：
1. AGENTS.md索引数量 = .trae/rules/目录文件数量
2. AGENTS.md索引中的文件名与实际文件名一致
3. 新增规则文件已添加到AGENTS.md索引
4. 删除规则文件已从AGENTS.md索引移除

## 维护流程
1. 新增规则文件：创建文件 → 更新AGENTS.md索引（数量+1）→ 校验一致性
2. 删除规则文件：删除文件 → 更新AGENTS.md索引（数量-1）→ 校验一致性
3. 重命名规则文件：重命名文件 → 更新AGENTS.md索引引用 → 校验一致性

## 禁止事项
| 禁止 | 说明 |
|------|------|
| ❌ 索引数量与实际不符 | AGENTS.md索引数量必须与.trae/rules/目录一致 |
| ❌ 索引文件名与实际不符 | 索引中的文件名必须与实际文件名完全一致 |
| ❌ 新增规则不更新索引 | 新增规则文件必须同步更新AGENTS.md索引 |
