# 2026-07-09 会话设计总结

> 本文件系统性整理了2026年7月8-9日跨会话的游戏设计讨论全貌，包含设计理念、核心决策、系统架构和后续方向。

---

## 一、设计背景

本次设计会话以"卡牌冒险者"项目为基础，在已有GDD-CORE-001（核心玩法架构）、GDD-COMBAT-001（战斗系统）、GDD-CHARACTER-001（角色系统）的框架下，进行了以下工作：

1. 制定了**项目协作协议**，建立"讨论→批准→实施"工作流
2. 完成了**四职业战斗系统**的全面设计
3. 重构了**装备系统**（从武器专精→D2六级品质+12槽全产卡）
4. 优化了**卡牌管理、资源系统和状态效果**
5. 参考《横跨方尖碑》《废墟战旗》和D&D规则进行了系统性复盘

## 二、核心设计理念

### 2.1 "万物皆卡牌"原则

一切游戏内容——攻击、防御、法术、装备效果——统一为卡牌格式。卡牌是玩家能力的唯一载体。

### 2.2 "没有无用卡牌"原则

不设计卡牌删除系统。通过专长重修和装备重铸实现牌库调整，而非简单移除。每张卡牌都有来源追踪(origin元数据)。

### 2.3 "品质驱动深度"原则

装备品质不仅决定属性数值，还决定产卡数量、词缀类型和策略选择。从普通(白)到传承(橙)的六级渐变提供渐进式深度。

### 2.4 "差异化而非数值化"原则

职业间的差异通过**机制差异**（怒气衰减/CP维护/法力规划/引导神力）体现，而非数值高低。英雄点系统的消耗效果改变的是**规则**而非**数值**。

### 2.5 "惩罚伴随强力"原则

强效状态（狂暴×2伤害、灼烧×2对盾）必须伴随负面效果（狂暴后防御归零、灼烧可被护盾吸收）。防止无代价的强力组合。

## 五、关键设计理念

### 5.1 空手vs装备的战略选择

| 策略 | 装备卡牌 | 修理费 | 牌库纯度 | 适合 |
|------|---------|--------|----------|------|
| 空手流 | 0 | 0G | 极高 | 盗贼CP连招 |
| 轻装流 | 3-6张 | 15-50G/场 | 高 | 战士/牧师 |
| 全装流 | 8-12张 | 40-160G/场 | 中 | 法师(法术书大) |

### 5.2 卡牌来源四分类

| 来源 | origin.type | 示例 |
|------|-------------|------|
| 职业 | profession | 战士核心牌·法师法术 |
| 装备 | equipment | 武器攻击牌·防具防御牌 |
| 技能 | skill | 碎甲击·影袭·奥术回想 |
| 通用 | universal | 急救·战备·专注 |

### 5.3 四级资源体系

```
战斗资源层
├── CE (通用·每回合3-6)     → 所有出牌
├── 职业能量 (怒气/CP/法力)   → 职业牌+能量机制
├── 英雄点 (战魂/暗影/超魔/神力) → 战略大招·行为条件获取
└── 装备耐久 (12-120)         → 装备牌消耗·修理经济

经济资源层
├── 金币 → 修理/购买/制作
└── 材料 (星尘/以太/魔晶/星核) → 制作/重铸/传承合成
```
