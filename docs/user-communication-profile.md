# 用户沟通画像

## 1. 表达风格
- 主风格：**直接型**
- 说明：用户提问简洁明确，多用"列出xxx""有哪些xxx""请执行xxx"句式，不拐弯抹角。关注执行结果和规范合规性。

## 2. 关注重点
- 主导向：**过程/质量控制导向**
- 说明：优先验证系统配置和基础知识，关注规则、Agent、Skill等概念是否正确；重视代码规范（参数命名、ID注释）；关注上下文健康度和系统稳定性。

## 3. 信息密度偏好
- 偏好：**低密度 + 渐进型**
- 说明：每次一个小问题，分散验证，确认一项再测下一项。从配置验证→功能实现→规范检查→系统检测逐步递进。

## 4. 纠错模式
- 模式：**直接纠错**
- 说明：发现问题直接指出（如"你的称呼/结语/总结丢了"），要求立即修正，不引导猜测。

## 6. 沟通优化建议
- AI 应该：简洁回答，一问一答，不冗长；注意称呼和结语的完整性；执行完任务后输出验证结果
- AI 不应该：长篇大论，一次给太多信息；遗漏称呼/结语；忽视代码规范要求
- 特别注意：用户会渐进式提问，AI 应保持回答精简；用户重视规范合规，需严格遵循规则
