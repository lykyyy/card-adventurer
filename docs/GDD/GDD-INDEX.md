## 3. 全局禁止清单

> 以下元素在整个项目中不存在，AI 不得在任何代码/文档中使用：

### 3.1 不存在的职业
- 狂战士（未设计）

### 3.2 不存在的游戏机制
- 吸血（未设计的卡牌属性）
- 魔法（未设计的属性类型）
- 冰冻（未设计的状态效果）

### 3.3 编号使用禁令
- 禁止使用未在ID-REGISTRY.md注册的编号
- 禁止使用废弃编号
- 禁止自行创造新编号格式
- 禁止用元素名称代替编号

### 3.4 文档操作禁令
- AI不得自行修改GDD（GDD由人工维护）
- AI不得跳过TDD直接从GDD生成代码
- AI不得在PDD中写入函数体代码

## 4. 系统间依赖关系

```
GDD-CORE-001（核心玩法架构）
├── 三层玩法（L1地图层 / L2网格层 / L3战斗层）
├── AP/EP/CE资源体系 + 金币
├── 职业能量系统（怒气/连击点/法力值）
├── 5×5网格事件系统
├── 地形差异化移动消耗
└── 难度动态匹配

GDD-CHARACTER-001（角色系统）
├── 种族定义 → 身份卡生成
├── 出身定义 → 战略卡牌库
├── 成长事件 → 战斗/战略卡牌库 + 身份卡
├── 属性系统 → 属性路径(13/16/19)
├── 技能系统 → 技能-战斗联动
├── 专长系统 → 通用专长 + 传奇专长
├── 等级系统 → 成长轮替
└── 传奇道途 → PL1-PL10

GDD-COMBAT-001（战斗系统）
├── 卡牌定义 → TDDH-COMBAT-001
├── 敌人AI → 战斗流程
├── 装备系统 → 装备栏
└── 奖励系统 → 战斗胜利

GDD-CRAFTING-001（制作与附魔系统）
├── 工作台系统 → 星港/太空船/法师塔三场景
├── 材料系统 → 4级稀有度·无限容量·获取速率控制
├── 配方系统 → 18配方·学识检定·大成功机制
```
