# GDD-BATTLEFIELD-001 · 双战场战斗系统

> 本文档定义地面3×3网格战和星界太空船战的完整战场系统。
> 继承 GDD-CORE-001 的职业/装备/卡牌/状态系统。

## 1. 多角色队伍架构

### 1.1 队伍组成

玩家操控4角色队伍，对应已设计的4职业：

```
玩家队伍
├── 战士（前排·怒气驱动·高CE）
├── 盗贼（中排输出·连击点驱动）
├── 法师（后排远程·法力值驱动）
└── 牧师（后排治疗·法力值+引导神力）
```

### 1.2 独立战斗能量（CE）

CE由角色系统决定，每角色独立资源池：

```
CE上限 = 职业基础 + CON调整值 + 身份卡修正 + 装备加成
CE恢复/回合 = 职业基础恢复 + 技能加成

职业基础：战士4 / 盗贼3 / 法师2 / 牧师2
CON调整值：CON≥12→+1 / CON≥16→+2
职业基础恢复：全职业+2/回合
技能加成：相关技能专家级时+1
```

| 角色示例 | 职业 | CON | 身份 | 装备 | CE上限 | CE恢复 |
|----------|------|-----|------|------|--------|--------|
| 战士 | 基础4 | 14(+1) | 士兵(+1) | — | 6 | 2 |
| 盗贼 | 基础3 | 14(+1) | — | — | 4 | 2 |
| 法师 | 基础2 | 10(+0) | — | 迅捷法袍(+1) | 3 | 2 |
| 牧师 | 基础2 | 14(+1) | — | — | 3 | 2 |

### 1.3 装备系统标注

> 角色装备系统（GDD-CORE-001 §5.3.4-5.3.8）当前版本不作修改。
> 标注：待后期平衡性调整阶段统一优化（多角色装备管理UI、12槽×4人的交互简化等）。

### 1.4 职业能量

职业能量（怒气/连击点/法力值）保持不变，每角色独立运转。

| 职业 | 职业能量 | 恢复 | 上限公式 |
|------|----------|------|----------|
| 战士 | 怒气 | 不自动恢复 | 10(基础)/12(狂战士专长) |
| 盗贼 | 连击点 | 不自动恢复 | 3(基础)/4(刺客专长) |
| 法师 | 法力值(每日) | 每日全恢复 | 5+INT调(最高10) |
| 牧师 | 法力值(每日) | 每日全恢复 | 4+WIS调(最高8) |

## 2. 地面3×3网格战斗系统

### 2.1 棋盘布局

```
       我方                             敌方
   后    中    前                   前    中    后
  ┌────┬────┬────┐              ┌────┬────┬────┐
  │ P1 │ P2 │ P3 │              │ E1 │ E2 │ E3 │
  ├────┼────┼────┤              ├────┼────┼────┤
  │ P4 │ P5 │ P6 │              │ E4 │ E5 │ E6 │
  ├────┼────┼────┤              ├────┼────┼────┤
  │ P7 │ P8 │ P9 │              │ E7 │ E8 │ E9 │
  └────┴────┴────┘              └────┴────┴────┘
```

- 列向排布：左→右 = 后排→中排→前排
- 双方前排面对面：P3↔E1 / P6↔E4 / P9↔E7

### 2.2 站位定位

| 位置 | 列 | 近战 | 远程 | 法术 | 被近战 |
|------|-----|------|------|------|--------|
| 前排(P3/P6/P9) | 右列 | ✅ 敌方前排 | ✅ 敌方全部 | ✅ 敌方全部 | ✅ 全部 |
| 中排(P2/P5/P8) | 中列 | 需移至前排 | ✅ 敌方全部 | ✅ 敌方全部 | 仅前排敌 |
| 后排(P1/P4/P7) | 左列 | 不可近战 | ✅ 敌方全部 | ✅ 敌方全部 | 不被近战 |

### 2.3 移动规则

| 操作 | CE消耗 | 说明 |
|------|--------|------|
| 横向移动 | 1CE | 左/右移动1列（后↔中↔前） |
| 纵向移动 | 1CE | 上/下移动1行（同列内换行） |
| 换位 | 0CE | 与相邻(上下左右)队友互换·全队1次/回合 |

> 不可斜角移动。一个格子限1人。

### 2.4 后排优势

| 优势 | 说明 |
|------|------|
| 不被近战 | 敌方近战攻击不可选择后排角色 |
| AOE减伤 | 受到AOE伤害减半 |
| 远程自由 | 远程攻击和法术可达敌方任意位置 |

### 2.5 敌方阵型模板

| 类型 | 阵型 | 战术特征 |
|------|------|----------|
| 杂兵群 | 前排全占·中后排空 | 数量压制·需AOE清理 |
| 精英+杂兵 | 前排精英·后排2杂兵 | 精英堵路·需突破或远程定点清除 |
| Boss | 后排中央(E2/E5/E8区域) | 远程AOE·需突破前排防线 |
| 包围 | 集中攻击我方某列 | 列突破策略·需纵向调动 |

### 2.6 战斗触发

地面战斗由L2网格·战斗牌和L3普通战斗触发，占全部战斗约80%。

```
┌─────── 回合开始阶段 ───────┐

└────────────────────────────┘
              ↓
┌─────── 行动阶段 ───────────┐
│ ★ 全队自由顺序·自由次数    │
│                             │
│ 可用行动：                  │
│  · 出牌（消耗角色CE）       │
│  · 移动（消耗1CE）          │
│  · 换位（0CE·全队1次）     │

│                             │

│                             │
│ ★ 玩家主动结束回合         │

└────────────────────────────┘
              ↓
┌─────── 敌方行动阶段 ───────┐
│ 敌方按预置AI执行            │

              ↓
```

```
  2. 可攻击到后排(远程) → 优先攻击后排施法者/治疗者

  4. 无可用目标 → 前进1列
```

## 8. 伤害公式

### 8.1 完整伤害公式

```
最终伤害 = [基础伤害 × (1 + 词缀修正) + 属性加成] × 状态倍率 - 减伤值

各项展开：
  基础伤害 = 卡牌原始伤害值
  词缀修正 = Σ(装备词缀加成) ← 上限+50%
  属性加成 = 武器伤害加成 + 属性面板加成
  状态倍率 = 标记(×1.5) / 狂暴(×2) / 虚弱(×0.5)
  减伤值 = 护盾值 + 装备减伤值
```

### 8.2 伤害结算顺序

```
打出攻击牌(伤害=X)
  → 1. 计算词缀加成：X × (1+词缀%)
  → 2. 加上属性加成：+武器伤害+属性面板
  → 3. 应用状态倍率：×标记/×狂暴/×虚弱
  → 4. 减去减伤值（伤害-护盾-减伤）
  → 5. 检测暴击（暴击率% → 伤害×1.5）
  → 6. 最终伤害 ≥ 1（最低1）
  → 7. 造成伤害 + 施加卡牌附带的状态效果
```

### 8.3 特殊伤害类型

| 类型 | 规则 | 示例 |
|------|------|------|
| 无视护盾 | 跳过步骤4的护盾扣除 | C-014毁灭之握(战士)·C-034星辰陨落(法师) |
| DOT伤害 | 回合结束时触发·不触发步骤1-4 | S-004流血·S-005灼烧 |
| 多段伤害 | 每段独立计算步骤1-6 | C-020双重打击(盗贼)·C-008连斩 |
| AOE伤害 | 每个目标独立计算全部步骤 | C-032烈焰风暴(法师)·C-046火球术(法师) |
| 反伤 | 受击时触发·固定数值不分步骤 | C-011格挡反击(战士) |

### 8.4 伤害数值基准

| 卡牌等级 | 标准伤害 | 标准护盾 | 标准治疗 |
|----------|----------|----------|----------|
| 0 CE | 5-10 | 4-5 | — |
| 1 CE | 15-20 | 8-10 | 15 |
| 2 CE | 25-35 | 12-15 | 25 |
| 3+ CE | 35-50 | 20+ | 35+ |

> 以上为基准值。职业牌和装备牌基于此基准进行职业特色调整。
