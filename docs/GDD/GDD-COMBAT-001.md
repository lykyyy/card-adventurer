# 战斗系统设计

## 1. 系统概述
回合制卡牌战斗系统，玩家通过出牌攻击敌人、获得防御、使用装备，击败敌人获得新卡牌奖励。支持多场战斗递进，第5场为Boss战。

## 2. 元素清单（穷举）★防幻觉防线1

> **数据源**：以下元素的详细数据存储在对应的 CSV 文件中，供 Godot/HTML 引擎直接读取。
> 本节仅描述各元素的设计意图和使用方式，具体数值见 CSV。

### 2.1 职业
- **数据文件**：`data/csv/professions.csv`
- **设计说明**：职业定义玩家的初始属性（生命值、法力值）和初始牌组。
- **当前职业**：战士（P001）— 高生命值，低法力值，初始携带 3×攻击 + 1×防御。
- **使用方式**：游戏开始时选择职业，从 CSV 读取 HP/MP/初始牌组，初始化玩家状态。

### 2.2 卡牌

> ⚠️ **架构变更（2026-07-09）**：原独立通用攻击/防御牌(C-001~C-003, C-005~C-009)已废弃，攻击/防御能力统一归入装备系统和专精/技能系统。详见 [[deprecated-designs]]。

- **数据文件**：`data/csv/cards.csv`
- **名称文本**：`data/csv/localization/element_names.csv`
- **设计说明**：卡牌分为四类来源 — 通用辅助牌、职业专属牌、装备关联牌、技能解锁牌。
  - **通用辅助牌**（C-004急救/C-072战备/C-073专注）：不依赖装备/职业的基础行动
  - **职业专属牌**（C-010~C-069）：各职业核心牌+法术/神术
  - **装备关联牌**（C-080~C-094）：通过装备武器/防具/饰品获得
  - **技能解锁牌**：通过技能达到专家级解锁（GDD-CHARACTER-001 §6.2）
- **使用方式**：从牌组抽到手中 → 消耗CE打出 → 执行效果 → 移入弃牌堆。

### 2.3 敌人
- **数据文件**：`data/csv/enemies.csv`
- **名称文本**：`data/csv/localization/element_names.csv`
- **设计说明**：5种敌人按难度递增，第5个为Boss。
  - 史莱姆（E001）：最弱，有分裂回血能力
  - 哥布林（E002）：会逃跑跳过回合
  - 骷髅兵（E003）：有骨盾防御技能
  - 狼人（E004）：可狂暴（攻击翻倍）
  - 暗影领主（E005）：Boss，高攻高血，综合技能组
- **AI行为**：敌人技能概率见 §4.2 敌人技能设计。
- **敌人技能数据**：`data/csv/enemy_skills.csv`

### 2.4 状态效果
- **数据文件**：`data/csv/status_effects.csv`
- **名称文本**：`data/csv/localization/element_names.csv`
- **设计说明**：状态效果临时影响战斗单位的属性。
  - 护盾（S001）：抵消伤害，持续当前回合。
  - 狂暴（S002）：攻击力翻倍，持续1回合（仅敌人使用）。
  - 虚弱（S003）：攻击力减半，持续2回合（预留，当前未使用）。

### 2.5 装备栏
- **数据文件**：`data/csv/equipment_slots.csv`
- **设计说明**：
  - 玩家初始有 1 个通用装备栏位，最多同时装备 1 件。
  - 装备卡打出后进入装备栏（不进弃牌堆），效果持续生效。
  - 卸下为免费动作，卸下后装备卡移入弃牌堆，下次洗牌时可重抽。
  - 战斗结束后，装备栏不回溯影响牌库。

## 4. 数值表

### 4.1 伤害公式
```
伤害 = 卡牌伤害值（最小为1）
```
- 实际伤害取自 `data/csv/cards.csv` 的 EFFECT_VALUE 列。
- 若有 damage_bonus 效果（如武器 C006），累加到伤害值。

### 4.2 敌人技能设计
- **技能数据**：`data/csv/enemy_skills.csv`
- **设计逻辑**：每个敌人有3个技能，按概率随机选择执行。概率分布遵循：主攻击 ~40-60% / 特殊技能 ~30-35% / 稀有技能 ~10-25%。
- **AI决策流程**：敌人回合 → 按概率随机选技能 → 执行效果（伤害/护盾/回血/状态附加）

### 4.3 回合规则
- 战斗开始：牌组 ← 牌库深拷贝，随机洗牌
- 回合开始：从牌组顶抽 5 张到手牌，法力重置为最大值
- 打出基本牌/技能牌：执行效果 → 卡牌移入弃牌堆
- 打出装备牌：卡牌进入装备栏（不进弃牌堆），持续生效
- 抽牌时牌组为空：弃牌堆洗入牌组，再从牌组抽牌
- 回合结束：弃置所有手牌

### 4.4 战斗递进规则
- 敌人血量公式：`50 + 20 × (战斗次数 - 1)`
- 第5场战斗为Boss战，使用暗影领主（E005）

### 4.5 卡牌收集规则
- 所有卡牌必须在持久化收集册中追踪，不得凭空产生或丢失
- 战斗专用卡牌数据（牌组/弃牌堆/装备）必须是收集册的深拷贝
- 战斗结束重置时清空所有临时卡牌数据（牌组/弃牌堆/装备）

### 4.6 牌库与牌组区分
- 牌库(collection)：持久化卡牌集合，跨战斗保存
- 牌组(deck)：临时战斗牌组，战斗开始时从牌库深拷贝生成，战斗结束后销毁
- 弃牌堆(discard)：临时存放已使用的基本/技能卡牌，牌组空时洗入牌组
- 牌库仅在战斗外被修改，或由特殊效果的卡牌在战斗中标注「影响牌库」时生效
- 战斗结束时，牌组/弃牌堆/装备栏均不回溯影响牌库

### 4.7 装备系统
- 玩家初始有 1 个装备栏位（见 `data/csv/equipment_slots.csv`）
- 装备卡牌打出时进入装备栏，不移入弃牌堆
- 装备效果持续生效（见 `data/csv/cards.csv`，TYPE=装备牌）
- 玩家可随时主动卸下装备（免费动作）
- 卸下后装备卡移入弃牌堆，下次洗牌时可重抽
- 装备栏中的卡牌在牌组为空时不会被洗入牌组

## 5. 状态机定义
| 当前状态 | 触发条件 | 目标状态 | 执行动作 |
|----------|----------|----------|----------|
| 战斗开始 | 页面加载 | 玩家回合 | 抽5张牌，法力重置 |
| 玩家回合 | 点击结束回合 | 敌人回合 | 弃手牌，敌人AI决策 |
| 玩家回合 | 打出装备牌 | 玩家回合 | 卡牌进入装备栏，效果持续生效 |
| 玩家回合 | 卸下装备 | 玩家回合 | 装备移入弃牌堆 |
| 敌人回合 | AI执行完毕 | 玩家回合 | 抽5张牌，法力重置 |
| 玩家回合 | 敌人HP≤0 | 战斗胜利 | 显示胜利，选卡奖励 |
| 敌人回合 | 玩家HP≤0 | 战斗失败 | 显示失败 |

| 事件名 | 触发条件 | 监听者 | 动作 |
|--------|----------|--------|------|
| on_damage | 造成伤害时 | UI系统 | 显示伤害数字 |
| on_heal | 恢复生命时 | UI系统 | 显示治疗数字 |

| on_turn_end | 回合结束 | 手牌系统 | 弃置所有手牌 |
| on_battle_end | 战斗结束 | 奖励系统 | 显示3选1卡牌 |

| on_deck_empty | 牌组为空 | 洗牌系统 | 将弃牌堆洗入牌组 |

## 7. 原型范围
- 做：单场战斗、6张卡牌、5种敌人、选卡奖励、视觉打磨
- 不做：多职业系统、卡牌升级、商店系统、存档系统
