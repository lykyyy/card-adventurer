# 卡牌冒险者 UI 重设计计划 — 《欺诈之地》风格 + DND 魔法船设定

## Summary

为「卡牌冒险者」（Card Adventurer）游戏创建一套全新的 `.design` 画布项目，融合 Klei《欺诈之地》（Griftlands）的手绘2D美术风格与 DND Spelljammer（魔法船）的太空奇幻设定，对游戏核心界面进行全面视觉重设计。项目产出为 9 个核心界面页面，覆盖从主菜单到战斗的完整游戏流程，适配桌面端响应式布局。

---

## Current State Analysis

### 现有代码分析
- **root.html**：单文件 HTML 游戏 MVP，包含 9 个场景（主菜单/角色创建7步流程/星域地图Canvas/5×5网格/战斗占位/星港/船员/装备/技能），全部使用 emoji 图标，深蓝+红色单色配色（`#0a0a1a` 背景 + `#e94560` 主色），UI 元素极简粗糙
- **mvp-battle.html**：战斗系统 MVP，3×3 网格战场 + 手牌区 + 状态条，同样是深蓝红色系，卡牌仅用色块表示
- **character-create.html**：角色创建页面（被 root.html 引用）
- **视觉问题**：无真实美术资源、无角色立绘、卡牌无设计感、地图为纯 Canvas 圆点连线、弹窗简陋、整体缺乏游戏质感

### 设定资源
- **DND 魔法船（Spelljammer）**：奇幻太空、晶壁球、燃素海（彩虹色海洋）、气囊、重力平面、魔舵驱动、魔法船航行
- **四大职业**：战士（怒气/红）、盗贼（连击点/绿）、法师（法力值/紫）、牧师（法力值/金）
- **三层玩法**：L1 星域地图 → L2 5×5 网格翻牌 → L3 回合制卡牌战斗
- **现有色板**：红`#e94560`、青绿`#4ecdc4`、紫`#a29bfe`、金`#ffd700`、绿`#2ecc71`、深蓝`#1a1a2e/#16213e/#0f3460`

### 《欺诈之地》风格特征（基于 Klei Entertainment 美术风格）
- **手绘2D**：粗犷黑色描边线条，手绘质感边框，略带卡通渲染
- **色彩**：暗色调背景 + 高饱和度角色/卡牌，暖色点缀（琥珀/橙/金），科幻西部/太空朋克混搭
- **卡牌**：精美边框装饰、费用宝石/晶石、角色立绘区域、效果文本区、稀有度颜色边框
- **地图**：手绘节点路径风格，非几何连线，有机感的曲线和地形标识
- **UI面板**：木质/金属质感边框，铆钉装饰，羊皮纸/金属板内面
- **字体**：标题使用装饰性/衬线字体，正文清晰易读
- **对话框**：角色立绘 + 名字标签 + 关系指示
- **动效**：卡牌悬停弹起、选中高亮、抽牌动画、伤害数字飘字

### 魔法船视觉融合方向
- 将欺诈之地的「西部/沙漠朋克」替换为「太空奇幻/星际航海」
- 背景：星空 + 星云 + 晶壁球光晕，燃素海的彩虹色渐变
- 边框：魔法符文 + 星图纹理 + 船体木板/金属板质感
- 图标：星座符号、魔法晶石、船舵、六分仪、魔舵等航海+魔法元素
- 色彩：在欺诈之地暗色调基础上，融入星界的紫色/蓝色/虹彩色

**项目名称**：`card-adventurer-ui`（显示名称：「卡牌冒险者 · 界面设计」）
**设备类型**：`desktop`（含响应式适配平板/移动端）
**操作模式**：`free-explore`（无现有 Design Library，自定义品牌 CSS）

### 品牌 CSS 设计方向（colors_and_type.css）

**色彩方案**（融合欺诈之地暗调+魔法船星界）：
- 主色：`#c4573a`（欺诈之地琥珀红/赤陶色，替代原纯红，更具手绘质感）
- 背景：`#1a1520`（深紫黑，星空感，替代原纯深蓝）
- 表面：`#2a2338`（面板色，替代原`#1a1a2e`）
- 边框：`#4a3f5c`（紫灰边框）
- 职业色：
  - 战士：`#d4523a`（赤焰红）
  - 盗贼：`#4ecdc4`（青绿）
  - 法师：`#9b7fd4`（奥术紫）
  - 牧师：`#f0c040`（神圣金）
- 状态色：成功`#5a9e3a`、警告`#d49030`、错误`#c03848`、信息`#5890c8`
- 稀有度：普通`#8a8090`、罕见`#4a90d4`、稀有`#9b50d4`、传奇`#d4a020`
- 燃素虹彩：`linear-gradient` 用于特殊装饰

**字体**：
- 标题：`'Cinzel', 'Noto Serif SC', serif`（衬线+魔法感）
- 正文：`'Segoe UI', 'Microsoft YaHei', sans-serif`
- 卡牌名称：`'Pirata One', 'Noto Serif SC', serif`（装饰性）
- 数字/费用：`'MedievalSharp', monospace`（中古风格数字）

**圆角**：克制尺度 `2px/6px/10px`（面板6px，按钮4px，卡牌10px）
**阴影**：静态表面用边框分层，浮动层（弹窗/tooltip/悬停卡牌）使用低alpha阴影
**边框风格**：2-3px 深色描边 + 内边框线，模拟手绘边框

### 图片资源计划
由于游戏为卡牌游戏类型，需要为各页面生成背景/装饰图片：
1. **主菜单背景**：星空+魔法船剪影+星云（宽屏）
2. **星域地图背景**：手绘风格星图纹理（含星座连线、星云色块）
3. **战斗背景**：太空战场（飞船甲板/小行星带/星界背景）
4. **卡牌背面图案**：统一卡背设计（魔法符文+星座图案）
5. **通用装饰**：魔法符文边框角饰、船舵/罗盘图标（SVG/CSS实现优先）

### 视觉设计关键决策

1. **卡牌设计**：每张卡牌有手绘边框（职业色）、费用晶石（圆形宝石，金色数字）、卡牌名称区、效果描述区、类型标签条。悬停时向上弹起 12px + 金色光晕
2. **地图节点**：用手绘风格的图标替代emoji，节点间用有机曲线连接（非直线），当前节点有脉冲光环动画
3. **战斗单位**：3×3格子中，每个单位框有手绘边框，HP条为渐变条（绿→黄→红），状态效果用小图标徽章，敌人意图用橙色警告框显示
4. **面板风格**：所有面板使用深色背景 + 2px描边 + 顶部/底部装饰线（铆钉/符文点缀），模拟魔法船船体木板和金属板
5. **按钮风格**：主按钮赤陶色底 + 深色描边 + 悬停高光；次按钮深色底 + 边框；危险按钮暗红
6. **弹窗/对话框**：居中面板 + 半透明黑色遮罩 + 顶部标题装饰条
7. **进度条**：船体/护盾/能源条使用渐变色 + 纹理（非纯色块），有容器边框

### 页面生成依赖顺序
- 所有页面共享同一 `colors_and_type.css`，可并行生成
- 但需先生成图片资源（背景图），再生成依赖图片的页面
- 实际顺序：品牌CSS → 图片资源 → 9个页面并行生成

## Assumptions & Decisions

1. **不修改现有代码**：这是一次新建设计项目，不覆盖/修改 `scripts/root.html` 等现有文件，产出独立的 `.design` 画布项目供预览
2. **桌面端优先**：按 desktop 尺寸设计（1920×1080 基准），内置响应式适配
3. **AI 生成图片**：背景/装饰图使用 AI 图像生成，卡牌图标用 CSS+emoji/Unicode符号+CSS图形混合实现（避免每张卡牌都需要生成图片）
4. **中文界面**：所有UI文本使用中文，与现有游戏保持一致
5. **游戏元素来源**：界面中出现的卡牌名/敌人名/地名均来自 GDD 和 ID-REGISTRY.md 中已注册元素，遵守防幻觉规则
6. **线性导航**：画布中页面按游戏流程线性连接（主菜单→角色创建→地图→网格→战斗→星港等），符合 Solo Design 默认拓扑
7. **无真实JS交互逻辑**：设计页面为静态视觉展示（含CSS悬停动效），不实现游戏逻辑
8. **风格融合度**：以欺诈之地的视觉语言（手绘描边、暗暖色调、卡牌质感）为骨架，注入魔法船的星空/奇幻/航海元素，而不是完全复制欺诈之地的西部科幻风格

## Verification Steps

1. **结构验证**：运行 `node {SKILL_DIR}/script/scan-design-directory.mjs <project-path> --expected-pages=9`，确认 9 个页面节点全部注册且 HTML 文件存在
2. **视觉验证**：每个页面在浏览器中可正常打开，无白屏、无布局错乱
3. **一致性验证**：所有页面使用统一的品牌 CSS（色彩/字体/边框/按钮风格一致）
4. **响应式验证**：关键页面（战斗、地图、菜单）在 1280px / 1920px 宽度下布局正常
5. **内容验证**：界面中出现的游戏元素名称（卡牌/敌人/职业/地名）均来自 GDD/ID-REGISTRY 已注册内容
6. **风格验证**：卡牌有手绘边框和费用显示、地图有节点路径感、面板有质感边框、整体暗色调+高饱和点缀符合欺诈之地+魔法船融合方向
