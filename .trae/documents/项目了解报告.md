## 五、核心设计要点

### 5.1 三层玩法架构(GDD-CORE-001)
- **L1 地图层**:AP行动力·星域探索·路径规划
- **L2 网格层**:EP探索点·5×5翻牌·区域事件
- **L3 战斗层**:CE战斗能量+职业能量·回合制卡牌战斗

### 5.2 四级资源体系
- AP(地图)/EP(网格)/CE(战斗)/金币(全层) + 职业能量(怒气/连击点/法力值)

### 5.3 四职业能量系统
| 职业 | 能量 | 上限 | 特点 |
|------|------|------|------|
| 战士 | 怒气 | 10 | 受伤/命中获取·回合衰减·战后归零 |
| 盗贼 | 连击点 | 3 | 基础攻击命中获取·受伤-1·战后归零 |
| 法师 | 法力值 | 5+INT(最高10) | 每日恢复·跨战斗持续 |
| 牧师 | 法力值 | 4+WIS(最高8) | 每日恢复·引导神力每战1次 |

### 5.4 双战场系统(GDD-BATTLEFIELD-001)【最新设计】
- **地面3×3网格战**(~80%):我方左/敌方右·列向排布(后/中/前)·移动消耗CE·后排不被近战
- **太空船5岗位战**(~20%):DND魔法船命名(星桥/燃素炉/魔导炮阵/晶壁护盾/星图仪)
- **双战场切换**:同一套牌库·角色状态延续

### 5.5 装备系统(已锁定)
- D2 六级品质:白/蓝/黄/绿/金/橙
- 12槽位全产卡:头/肩/躯/手/腰/腿/足/主手/副手/颈/戒1/戒2
- 耐久度消耗:打出装备卡=消耗1耐久·修理经济闭环
- 卡牌来源追踪:origin元数据(profession/equipment/skill/universal)

### 5.6 状态效果网络(8状态)
S-001护盾/S-002狂暴/S-003虚弱/S-004流血/S-005灼烧/S-006减速/S-007致盲/S-008标记
- 5组互动规则(如:灼烧+流血→流血×2,标记+伤害→×1.5)
- 平衡约束:强效必带惩罚·单目标上限4状态

## 七、协作体系(强制规则)

### 7.1 工作流铁律
```
讨论 → 批准 → 实施(6阶段写入流程)
生成 → 残留预审 → 系统校核 → 人工确认 → 写入 → 事后校验
```

### 7.2 8个 Agent 角色
project-director / gdd-lead / tech-lead / verify-lead / writer-agent(唯一写入) / doc-engineer / perf-expert / memory-keeper

### 7.3 关键铁律
- **ID-REGISTRY 唯一权威源**:所有编号必须先注册再写入
- **防幻觉**:代码元素必须在GDD元素清单中存在
- **GDD 保护**:AI 不得自行修改 GDD(由人工维护)
- **PDD 自动维护**:代码修改后必须同步更新PDD
- **背景设定查询**:设计前必查背景一致性

### 7.4 称呼与上下文健康度
- 用户称呼:**先生**
- 每轮回复必须包含:称呼(开头) + 结语(末尾) + 本轮总结
- 三级警报:绿灯(三者俱全)/黄灯(失1)/红灯(失2+)
