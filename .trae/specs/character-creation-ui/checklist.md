# 角色创建与展示 检查清单

## 阶段1：角色创建UI

### 页面框架
- [ ] character-create.html单文件·零外部依赖·纯原生JS/CSS
- [ ] 进度条组件：7步·已完成(绿)/当前(红)/未完成(灰)
- [ ] 步骤切换动画：slide或fade < 200ms
- [ ] "上一步"/"下一步"导航按钮·第1步隐藏"上一步"·最后步骤显示"完成"
- [ ] 深色太空主题CSS（#1a1a2e/#e94560配色）

### 步骤1·种族选择
- [ ] 4种族卡片(RACE-001~004)可点击
- [ ] 每张卡片显示：名称+插图位+属性初始值+种族特色
- [ ] 选中卡片高亮红色边框+发光效果
- [ ] 选中后"下一步"按钮激活（未选时为disabled灰色）
- [ ] 人类额外显示"自选技能+1"提示

### 步骤2·出身选择
- [ ] 6出身卡片(ORIGIN-001~006)可点击
- [ ] 每张卡片显示：名称+特性摘要+剧情钩子
- [ ] 选中后显示：起始金币+物品预览
- [ ] 已选数据在回退时保留

### 步骤3-5·成长事件
- [ ] 3轮成长事件·正确标识当前轮次（事件一/二/三）
- [ ] 每轮3选项卡片：选项A(战斗·红色底)/选项B(策略·蓝色底)/选项C(种族·金色底)
- [ ] 选项展示：事件名称+奖励卡牌名称/图标+故事标签
- [ ] 选中后显示：标签已记录·不可回退修改（仅可重选当前轮）
- [ ] 3轮选择互不影响·数据逐轮追加

### 步骤6·身份卡
- [ ] 自动合成身份卡（基于种族+出身+3标签）
- [ ] 展示：称号(大字)·属性加成(列表)·身份特性(描述)·背景叙事(段落)
- [ ] 无法修改·仅展示确认

### 步骤7·技能分配
- [ ] 6技能(SKILL-01~06)复选框列表
- [ ] 每技能显示：名称+主/副属性+战斗卡牌预览
- [ ] 实时计数器："已选 2/3"
- [ ] 超过3个时剩余复选框disabled
- [ ] 恰好3个时"完成"按钮激活

### 数据传递
- [ ] 全局state对象：{race,origin,events:[],tags:[],skills:[],identity:{}}
- [ ] "上一步"回退保留所有已填数据
- [ ] 步骤切换无数据丢失
- [ ] 支持从任意步骤退出后重新进入（localStorage暂存）

## 阶段2：角色展示面板

### 属性面板

- [ ] 已选3技能列表（熟练标记⭐）
- [ ] 身份卡信息：称号+特性+叙事
- [ ] 实时数据与创建步骤数据一致

### 牌库浏览器

- [ ] 每张牌显示：标签栏·名称·CE消耗·效果简写
- [ ] 过滤栏：按类型(攻击/防御/辅助/控制)·按CE(0/1/2/3+)
- [ ] 过滤切换 < 100ms
- [ ] 点击弹出详情弹窗：完整效果描述·标签·来源(职业/种族/技能)
- [ ] 参考《欺诈之地》视觉风格（卡片式·阴影·hover缩放）

### 数据桥接
- [ ] "进入战斗"按钮可见

- [ ] mvp-battle.html接收参数并替换对应职业位的预设角色
