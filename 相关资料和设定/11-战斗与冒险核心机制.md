# 11 — 战斗与冒险核心机制

> 本文档详细提取DND 5E中战斗系统、冒险机制、检定系统的完整规则，为卡牌冒险者的核心玩法设计提供参考。
> 来源：5E PHB 第7章（属性值应用）、第8章（冒险）、第9章（战斗）；DMG 第8章（运作游戏）。

---

## 一、属性检定系统（PHB 第7章）

### 1.1 核心检定公式

```
d20 + 属性调整值 + 熟练加值（如熟练） ≥ DC（难度等级）= 成功
```

### 1.2 难度等级（DC）

| 难度 | DC | 说明 |
|------|-----|------|
| 非常简单 Very Easy | 5 | 几乎不可能失败 |
| 简单 Easy | 10 | 普通人一半概率成功 |
| 中等 Medium | 15 | 需要一定训练 |
| 困难 Hard | 20 | 需要专门训练 |
| 非常困难 Very Hard | 25 | 需要专家级能力 |
| 几乎不可能 Nearly Impossible | 30 | 需要传奇级能力 |

### 1.3 优势与劣势（Advantage / Disadvantage）

- **优势**：掷两个d20，取较高的结果
- **劣势**：掷两个d20，取较低的结果
- 优势/劣势不叠加，多个来源只算一次
- 优势/劣势互相对消

### 1.4 豁免检定（Saving Throw）

六大属性的豁免检定公式：
```
d20 + 属性调整值 + 熟练加值（如熟练） ≥ DC
```

| 常见豁免触发 | 相关属性 |
|-------------|----------|
| 抵抗毒素/疾病/死亡 | 体质 CON |
| 躲避火球/陷阱 | 敏捷 DEX |
| 抵抗魅惑/恐惧 | 感知 WIS |
| 抵抗幻术 | 智力 INT |
| 抵抗推撞/擒抱 | 力量 STR |
| 抵抗放逐/位面效果 | 魅力 CHA |

### 1.5 对抗检定（Contested Check）

双方各掷 d20 + 调整值，比较结果。常见于：
- 擒抱（STR运动 vs STR运动/DEX体操）
- 推撞（STR运动 vs STR运动/DEX体操）
- 隐匿 vs 察觉（DEX隐匿 vs WIS察觉）

## 二、冒险机制（PHB 第8章）

### 2.1 时间管理

| 单位 | 用途 |
|------|------|
| 1轮 Round | 6秒，战斗中 |
| 1分钟 | 探索房间、检查物品 |
| 10分钟 | 短休、搜索区域 |
| 1小时 | 旅行、社交互动 |
| 1天 | 长休、长途旅行 |
| 1周 | 休整期活动 |

### 2.2 移动速度

| 移动类型 | 速度 |
|----------|------|
| 步行 | 种族基础速度（25-35尺） |
| 攀爬 Climbing | 步行速度减半（除非特定能力） |
| 游泳 Swimming | 步行速度减半（除非特定能力） |
| 潜行 Sneaking | 步行速度减半（保持隐匿） |
| 困难地形 Difficult Terrain | 每尺移动消耗2尺 |

### 2.3 旅行速度

| 速度 | 每分钟 | 每小时 | 每天（8小时） |
|------|--------|--------|--------------|
| 快速 Fast | 400尺 | 4英里 | 30英里 |
| 普通 Normal | 300尺 | 3英里 | 24英里 |
| 慢速 Slow | 200尺 | 2英里 | 18英里 |

- **快速**：察觉劣势（-5被动察觉）
- **慢速**：可以保持隐匿

### 2.4 旅行中的活动

| 活动 | 说明 |
|------|------|
| 导航 Navigate | 生存检定，防止迷路 |
| 绘制地图 Draw Map | 不需要检定 |
| 追踪 Track | 生存检定，追踪其他生物 |
| 觅食 Forage | 生存检定，寻找食物和水 |
| 警戒 Keep Watch | 被动察觉，发现威胁 |

### 2.5 环境危害

| 危害 | 效果 |
|------|------|
| 极端高温 Extreme Heat | 每小时CON豁免，失败=力竭 |
| 极端低温 Extreme Cold | 每小时CON豁免，失败=力竭 |
| 强风 Strong Wind | 远程攻击劣势，飞行困难 |
| 暴雨 Heavy Precipitation | 视野受限，火焰伤害减半 |
| 高海拔 High Altitude | 超过10,000尺每小时CON豁免 |
| 水下 Underwater | 憋气（CON×1分钟），武器劣势（除特定武器） |
| 黑暗 Darkness | 重度遮蔽，盲视状态 |

### 2.6 食物与水

| 需求 | 每日 | 不足后果 |
|------|------|----------|
| 食物 Food | 1磅 | 超过3+CON日不进食 → 力竭 |
| 水 Water | 1加仑（正常）/ 2加仑（炎热） | 超过1日不饮水 → 力竭 |

### 2.7 力竭（Exhaustion）

| 等级 | 效果 |
|------|------|
| 1 | 属性检定劣势 |
| 2 | 速度减半 |
| 3 | 攻击和豁免劣势 |
| 4 | HP上限减半 |
| 5 | 速度降为0 |
| 6 | 死亡 |

- 长休恢复1级力竭

### 2.8 休息规则

| 休息类型 | 时长 | 恢复 |
|----------|------|------|
| 短休 Short Rest | 1小时 | 可花费生命骰恢复HP，恢复部分职业特性 |
| 长休 Long Rest | 8小时（至少6小时睡眠） | 恢复全部HP和生命骰（最多一半），恢复全部法术位和职业特性 |

## 三、战斗系统（PHB 第9章）

### 3.1 战斗流程（Order of Combat）

| 步骤 | 动作 |
|------|------|
| 1. 确定突袭 Determine Surprise | DM判定哪方被突袭（察觉 vs 隐匿对抗） |
| 2. 确定位置 Establish Positions | 决定各角色和怪物的初始位置 |
| 3. 掷先攻 Roll Initiative | 所有人掷d20+DEX，从高到低排列 |
| 4. 按回合行动 Take Turns | 按先攻顺序循环 |
| 5. 开始下一轮 Begin Next Round | 上一轮结束后，回到先攻最高者 |

### 3.2 突袭（Surprise）

- 被突袭者在第一轮中不能移动或使用动作
- 被突袭者在该轮结束后才能使用反应
- 突袭者第一轮正常行动

### 3.3 先攻（Initiative）

```
先攻 = d20 + DEX调整值 + 其他加值（如警觉专长+5）
```

### 3.4 你回合中的行动（Your Turn）

每个回合包含：
- **动作 Action**（1个）
- **附赠动作 Bonus Action**（如有）
- **移动 Movement**（步行速度上限）
- **反应 Reaction**（1个/轮，可在他人回合使用）
- **自由物件交互**（1个，如拔武器/开门）

### 3.5 战斗动作（Actions in Combat）

| 动作 | 说明 |
|------|------|
| **攻击 Attack** | 进行一次近战或远程攻击 |
| **施法 Cast a Spell** | 施展一个施法时间为1动作的法术 |
| **疾走 Dash** | 本回合获得额外移动（等于速度） |
| **撤离 Disengage** | 本回合移动不触发借机攻击 |
| **闪避 Dodge** | 本回合攻击有劣势，DEX豁免优势 |
| **协助 Help** | 协助队友攻击（优势）或技能检定 |
| **躲藏 Hide** | DEX隐匿检定，成功则隐藏 |
| **就绪 Ready** | 准备一个动作，在触发条件满足时以反应执行 |
| **搜索 Search** | WIS察觉或INT调查检定 |
| **使用物件 Use an Object** | 使用非攻击性的物品 |

### 3.6 移动与位置（Movement and Position）

| 概念 | 说明 |
|------|------|
| 站立起身 Standing Up | 消耗一半移动速度 |
| 匍匐爬行 Crawling | 每尺消耗1尺额外移动 |
| 困难地形 Difficult Terrain | 每尺消耗2尺移动 |
| 挤入空间 Squeezing | 可进入比自己小一号的空间，每尺消耗2尺 |

### 3.7 借机攻击（Opportunity Attack）

- 触发：敌对生物离开你的触及范围
- 消耗：反应
- 攻击：一次近战攻击

### 3.8 双武器战斗（Two-Weapon Fighting）

- 条件：双手各持一把轻型武器
- 使用攻击动作后，可消耗附赠动作进行副手攻击
- 副手攻击不添加属性调整值到伤害（除非有双武器战斗风格）

### 3.9 擒抱与推撞（Grappling & Shoving）

**擒抱 Grapple：**
- 消耗1次攻击（替代攻击）
- 对抗检定：STR运动 vs STR运动/DEX体操
- 成功：目标被擒抱（速度=0）
- 目标可使用动作进行对抗逃脱

**推撞 Shove：**
- 消耗1次攻击
- 对抗检定：STR运动 vs STR运动/DEX体操
- 成功：推倒（倒地）或推开5尺

## 四、攻击与伤害（PHB 第9章续）

### 4.1 攻击检定

```
近战攻击：d20 + STR调整值 + 熟练加值
远程攻击：d20 + DEX调整值 + 熟练加值
法术攻击：d20 + 施法属性调整值 + 熟练加值
```

### 4.2 伤害掷骰

```
近战武器伤害：武器伤害骰 + STR调整值
远程武器伤害：武器伤害骰 + DEX调整值
副手武器伤害：武器伤害骰（不加属性调整值）
```

### 4.3 重击（Critical Hit）

- 自然20 = 重击
- 所有伤害骰掷两次（包括偷袭、至圣斩等额外骰子）
- 属性调整值不翻倍

### 4.4 掩护（Cover）

| 掩护程度 | AC和DEX豁免加值 |
|----------|-----------------|
| 半身掩蔽 Half Cover | +2 |
| 四分之三掩蔽 Three-Quarters Cover | +5 |
| 全掩蔽 Total Cover | 不能被直接攻击 |

### 4.5 远程攻击限制

| 情况 | 效果 |
|------|------|
| 近战中的远程攻击 | 劣势（无论目标是谁） |
| 长射程（Long Range） | 劣势 |
| 倒地目标 | 近战优势 / 远程劣势 |

### 4.6 伤害抗性与易伤

| 类型 | 效果 |
|------|------|
| 抗性 Resistance | 伤害减半 |
| 易伤 Vulnerability | 伤害翻倍 |
| 免疫 Immunity | 不受伤害 |

## 五、死亡与治疗（PHB 第9章）

### 5.1 生命值归零

当HP降至0：
- 立即倒地（除非还剩HP）
- 进行**死亡豁免**（Death Saving Throw）

### 5.2 死亡豁免

每回合开始时掷d20（无调整值）：
- **10或以上**：成功1次
- **9或以下**：失败1次
- **自然20**：回复1 HP，恢复意识
- **自然1**：算作2次失败

| 结果 | 条件 |
|------|------|
| 稳定 Stabilized | 3次成功 |
| 死亡 Death | 3次失败 |
| 即死 Instant Death | 剩余伤害 ≥ HP上限 |

### 5.3 治疗

| 来源 | 效果 |
|------|------|
| 法术治疗 | 法术指定骰子+属性调整值 |
| 治疗药水 | 2d4+2 ~ 10d4+20 |
| 生命骰（短休） | 掷生命骰+CON调整值 |
| 长休 | 恢复全部HP |
| 急救（稳定） | WIS医药检定 DC 10 |

## 六、运作游戏（DMG 第8章）

### 6.1 玩家类型与应对

| 玩家类型 | 偏好 | 应对策略 |
|----------|------|----------|
| 表演者 Acting | 角色扮演、对话 | 提供丰富的NPC互动 |
| 探索者 Exploring | 发现新地点、秘密 | 隐藏秘密和彩蛋 |
| 煽动者 Instigating | 引发事件、制造混乱 | 让他们的行为产生后果 |
| 战斗者 Fighting | 战斗、战术 | 提供多样化的战斗 |
| 优化者 Optimizing | 角色强化、新装备 | 提供稳定的成长路径 |
| 解谜者 Problem Solving | 推理、策略 | 提供谜题和策略挑战 |
| 叙事者 Storytelling | 故事深度、角色发展 | 将角色背景融入故事 |

### 6.4 追逐规则（Chase）

- 追逐者与逃跑者距离：初始随机确认
- 每轮：每个参与者可疾走（CON检定，失败=力竭）
- 障碍物：DEX/DEX体操检定避开
- 追逐结束：一方逃脱或追上

## 七、对卡牌冒险者的设计启示

### 7.1 战斗系统映射
- 先攻 d20+DEX → 速度属性决定行动顺序
- 动作/附赠/移动/反应 → 每回合行动点数（AP）
- 攻击检定 → 攻击卡牌效果
- 伤害类型 → 卡牌标签
- 重击 d20自然20 → 暴击卡牌效果

### 7.2 卡牌战斗简化方向
- 省略位置/移动系统 → 简化为"前线/后排"
- 保留动作经济 → 每回合1张主卡牌+N张辅助卡牌
- 保留优势/劣势 → 强化/削弱状态卡牌
- HP/死亡豁免 → 玩家生命值+复活机制

### 7.3 冒险机制映射
- 短休/长休 → 关卡间隙恢复
- 力竭 → 负面状态卡牌
- 环境危害 → 环境卡牌
- DC检定 → 技能/事件卡牌判定

### 7.4 数值参考
- 标准DC：10(简单)/15(中等)/20(困难)
- 标准伤害：1d8(基础)/2d6(中等)/4d6+(高级)
- 标准HP：1级约10HP, 20级约200HP
- 标准AC：10(无甲)~18(板甲)
- 熟练加值：+2(Lv1)~+6(Lv20)
