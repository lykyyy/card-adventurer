# 10 — 战役与冒险构筑

> 本文档详细提取DND 5E城主指南（DMG）中关于战役构建、冒险设计、遭遇创建、NPC设计、奖励系统等内容。
> 来源：5E DMG 第3章（创建冒险）、第4章（NPC）、第5章（冒险环境）、第6章（冒险之余）、第7章（宝藏）。

---

## 一、创建冒险（DMG 第3章）

### 1.1 大冒险的基本要素

| 要素 | 说明 |
|------|------|
| 明确的冒险目标 | 玩家需要知道为什么要去做这件事 |
| 令人信服的动机 | 反派必须有合理的动机，而非"因为他是坏人" |
| 有意义的抉择 | 玩家的选择必须真正影响故事走向 |
| 适当的挑战 | 不能太简单也不能太难 |
| 奖励与成就感 | 克服困难后有实质性的回报 |

### 1.2 冒险故事结构

| 阶段 | 内容 |
|------|------|
| 1. 钩子 Hook | 吸引玩家进入冒险的事件或信息 |
| 2. 展开 Development | 探索、调查、收集线索 |
| 3. 高潮 Climax | 最终对决或关键抉择 |
| 4. 收尾 Resolution | 结果、奖励、后续线索 |

### 1.3 冒险类型

| 类型 | 特征 |
|------|------|
| 地城探险 Dungeon Crawl | 探索地下城，战斗为主 |
| 阴谋诡计 Intrigue | 政治、间谍、暗杀 |
| 神秘事件 Mystery | 调查、推理、解谜 |
| 荒野求生 Wilderness Survival | 探索、生存、随机遭遇 |
| 攻城略地 Warfare | 大规模战斗、攻城 |
| 位面旅行 Planar Adventure | 跨越位面、异界冒险 |

### 1.4 困境 Complications

冒险中引入困境增加戏剧性：

| 困境类型 | 示例 |
|----------|------|
| 道德困境 | 救一个人还是救一群人 |
| 时间压力 | 三天内必须完成，否则灾难降临 |
| 资源匮乏 | 食物/水/弹药耗尽 |
| 背叛 | 信任的NPC突然反水 |
| 意外发现 | 发现了比原任务更重大的威胁 |

## 二、创建遭遇（Encounter Design）

### 2.1 遭遇难度判定

使用 **XP阈值** 判定遭遇难度，基于队伍等级和人数：

| 角色等级 | 简单 Easy | 普通 Medium | 困难 Hard | 致命 Deadly |
|----------|-----------|-------------|-----------|-------------|
| 1级 | 25 XP | 50 XP | 75 XP | 100 XP |
| 2级 | 50 XP | 100 XP | 150 XP | 200 XP |
| 3级 | 75 XP | 150 XP | 225 XP | 400 XP |
| 4级 | 125 XP | 250 XP | 375 XP | 500 XP |
| 5级 | 250 XP | 500 XP | 750 XP | 1,100 XP |
| 6级 | 300 XP | 600 XP | 900 XP | 1,400 XP |
| 7级 | 350 XP | 750 XP | 1,100 XP | 1,700 XP |
| 8级 | 450 XP | 900 XP | 1,400 XP | 2,100 XP |
| 9级 | 550 XP | 1,100 XP | 1,600 XP | 2,400 XP |
| 10级 | 600 XP | 1,200 XP | 1,900 XP | 2,800 XP |

### 2.2 遭遇难度计算步骤

1. 确定每个角色的XP阈值（查表）
2. 将所有角色的阈值相加 = 队伍总XP阈值
3. 将所有怪物的XP相加
4. 根据怪物数量应用**倍率修正**：
   - 1个怪物：×1
   - 2个怪物：×1.5
   - 3-6个怪物：×2
   - 7-10个怪物：×2.5
   - 11-14个怪物：×3
   - 15+个怪物：×4
5. 修正后XP与队伍阈值比较

### 2.3 每日遭遇预算（Adventuring Day XP）

| 等级 | 每日调整后XP |
|------|-------------|
| 1级 | 300 XP |
| 2级 | 600 XP |
| 3级 | 1,200 XP |
| 4级 | 1,700 XP |
| 5级 | 3,500 XP |
| 6级 | 4,000 XP |
| 7级 | 5,000 XP |
| 8级 | 6,000 XP |
| 9级 | 7,500 XP |
| 10级 | 9,000 XP |

> 每日推荐6-8场中等遭遇，或4-5场困难遭遇。

### 2.4 遭遇多样性设计

| 遭遇类型 | 占比建议 |
|----------|----------|
| 战斗遭遇 Combat | 50-60% |
| 探索遭遇 Exploration | 20-30% |
| 社交遭遇 Social | 10-20% |
| 陷阱/谜题 Trap/Puzzle | 10% |

## 三、创建NPC（DMG 第4章）

### 3.1 NPC设计要素

| 要素 | 说明 |
|------|------|
| 名字与外貌 | 让NPC容易被记住 |
| 职业/身份 | 在游戏世界中的角色 |
| 动机与目标 | 他们想要什么，为什么 |
| 性格特征 | 一个突出特点即可 |
| 关系网 | 与谁有关系，盟友/敌人 |
| 秘密 | 隐藏的真相 |

### 3.2 NPC类型

| 类型 | 说明 |
|------|------|
| 队友 NPC Party Members | 随同冒险者一起行动 |
| 联络员 Contacts | 提供信息、任务、资源 |
| 雇员 Hirelings | 受雇的助手（佣兵、向导等） |
| 小角色 Extras | 路人、店主、守卫等 |
| 反派 Villains | 主要的敌对NPC |

### 3.3 反派设计

| 要素 | 说明 |
|------|------|
| 明确的目标 | 反派想要达到什么目的 |
| 合理的动机 | 为什么这样做（不能只是"因为邪恶"） |
| 资源与能力 | 反派拥有什么力量/资源 |
| 弱点 | 可以被击败的方式 |
| 计划 | 如果玩家不干预，反派的计划会怎样发展 |
| 升级空间 | 反派可以在战役中成长/变化 |

### 3.4 反派职业选项

给反派添加职业等级：
- 使用标准职业等级表
- 生命骰替换为反派职业等级
- 获得对应的职业特性

## 四、冒险环境（DMG 第5章）

### 4.1 地下城设计

| 要素 | 说明 |
|------|------|
| 入口 | 如何进入地下城 |
| 房间类型 | 守卫室、陷阱室、宝藏室、Boss室 |
| 通道 | 走廊、楼梯、竖井、密道 |
| 生态 | 什么生物居住在此，它们吃什么 |
| 历史 | 这个地下城是谁建造的，为什么被废弃 |

### 4.2 野外环境

| 环境 | 特征 | 危险 |
|------|------|------|
| 森林 | 遮蔽视野，自然生物 | 野兽、毒虫、植物 |
| 沙漠 | 极端温度，水源稀缺 | 脱水、沙暴、流沙 |
| 山脉 | 高地，氧气稀薄 | 坠落、雪崩、风暴 |
| 沼泽 | 湿地，毒气 | 疾病、流沙、怪物 |
| 海洋 | 无边水域，无法休息 | 风暴、海怪、溺水 |
| 星界/太空 | 无重力，魔法异常 | 星界生物、位面裂隙 |

### 4.3 聚居地设计

| 要素 | 说明 |
|------|------|
| 规模 | 村庄/城镇/城市/大都市 |
| 统治者 | 谁在管理这个地方 |
| 经济 | 以什么为生（农业/贸易/矿业/魔法） |
| 守卫力量 | 有什么防御力量 |
| 派系 | 城内的势力分布 |
| 特色 | 这个地方有什么独特之处 |

### 4.4 陷阱设计

| 陷阱类型 | 说明 |
|----------|------|
| 机械陷阱 | 箭矢、落石、陷坑、摆锤 |
| 魔法陷阱 | 符文、符文、诅咒、传送 |
| 环境陷阱 | 塌方、毒气、岩浆、洪水 |

陷阱设计要素：
- **触发条件**：压力板/绊线/魔法/视觉/计时
- **DC**：发现陷阱的DC和解除陷阱的DC
- **伤害**：轻度（1d10，1-4级）→ 危险（4d10，5-10级）→ 致命（10d10+，11-16级）
- **反制措施**：可以跳过、解除或利用

## 五、冒险之余（DMG 第6章）

| 活动 | 时间 | 花费 | 效果 |
|------|------|------|------|
| 制造物品 Crafting | 每5 gp/天 | 半价材料费 | 制造非魔法物品 |
| 练习专业 Practicing Profession | 30天 | — | 维持基本生活 |
| 休养 Recuperating | 3天 | — | 疾病/毒素豁免优势 |
| 研究 Research | 7天 | 50 gp | 获取知识/线索 |
| 训练 Training | 250天 | 250 gp | 获得新语言或工具熟练 |
| 抄写法术 Scribing Scroll | 按法术等级 | 见表 | 制造法术卷轴 |
| 经营生意 Running Business | 30天 | 经营成本 | 维持或扩张生意 |
| 犯罪 Crime | 7天 | 25 gp | 获取额外金币（有风险） |
| 角斗 Pit Fighting | 5天 | — | 赚取金币（战斗检定） |
| 宗教服务 Religious Service | 10天 | — | 获取神祇的恩惠/信息 |

| 稀有度 | 制造时间 | 制造花费 | 最低等级 |
|--------|----------|----------|----------|

| 非普通 Uncommon | 20天 | 500 gp | 3级 |

### 5.3 战役跟进（Campaign Tracking）

| 跟踪项 | 内容 |
|--------|------|
| 日历 | 记录游戏中过了多少天 |

## 七、对卡牌冒险者的设计启示

### 7.1 冒险结构卡牌化
- 钩子 → **任务卡牌**（触发新冒险）
- 遭遇 → **遭遇卡牌**（战斗/探索/社交分类）
- 高潮 → **Boss卡牌**（最终战斗）
- 收尾 → **奖励卡牌**（战利品/经验）

### 7.2 遭遇设计映射
- 怪物XP → 敌人强度等级
- 每日遭遇预算 → 每章/每关的战斗数量
- 遭遇多样性 → 战斗/探索/社交/陷阱卡牌比例

### 7.3 奖励系统映射
- 金币 → 游戏货币
- 魔法物品 → 装备卡牌
- 经验值 → 升级/解锁新卡牌
- 灵感 → 一次性增益卡牌
- 休整期活动 → 关卡间管理阶段

### 7.4 NPC系统映射
- 队友 → 同伴卡牌
- 联络员 → 任务发布卡牌
- 反派 → Boss卡牌/敌人卡牌
- 派系声望 → 声望值系统
