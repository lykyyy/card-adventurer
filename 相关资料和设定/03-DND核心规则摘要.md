# 03 — DND 核心规则摘要

> 本文档提取DND 5E核心规则中与卡牌冒险者设计相关的部分，聚焦于可转化为卡牌机制的系统。
> 来源：5E 玩家手册（PHB）、城主指南（DMG）、怪物图鉴（MM）

---

## 一、六大属性（Ability Scores）

| 属性 | 英文 | 影响 |
|------|------|------|
| 力量 | Strength (STR) | 近战攻击、负重、力量豁免 |
| 敏捷 | Dexterity (DEX) | 远程攻击、护甲等级、先攻、敏捷豁免 |
| 体质 | Constitution (CON) | 生命值、体质豁免 |
| 智力 | Intelligence (INT) | 法师施法、调查、智力豁免 |
| 感知 | Wisdom (WIS) | 牧师施法、察觉、感知豁免 |
| 魅力 | Charisma (CHA) | 术士/吟游诗人施法、社交、魅力豁免 |

### 属性调整值（Modifier）

| 属性值 | 调整值 |
|--------|--------|
| 8-9 | -1 |
| 10-11 | +0 |
| 12-13 | +1 |
| 14-15 | +2 |
| 16-17 | +3 |
| 18-19 | +4 |
| 20 | +5 |

## 二、核心战斗规则

### 2.1 攻击检定（Attack Roll）

- d20 + 熟练加值 + 属性调整值 ≥ 目标AC = 命中
- 自然20 = 重击（Critical Hit），伤害骰翻倍
- 自然1 = 必失

### 2.2 护甲等级（Armor Class / AC）

| 护甲类型 | 基础AC |
|----------|--------|
| 无护甲 | 10 + DEX |
| 皮甲 | 11 + DEX |
| 链甲衫 | 13 + DEX（上限2） |
| 胸甲 | 14 + DEX（上限2） |
| 链甲 | 16 |
| 板甲 | 18 |

### 2.3 伤害类型

| 类型 | 说明 |
|------|------|
| 穿刺 | 矛、箭、刺剑 |
| 挥砍 | 剑、斧 |
| 钝击 | 锤、棍 |
| 火焰 | 火球术、龙息 |
| 冷冻 | 冰风暴 |
| 闪电 | 闪电束 |
| 强酸 | 强酸箭 |
| 雷鸣 | 音波伤害 |
| 力场 | 魔法力场 |
| 黯蚀 | 负能量 |
| 光耀 | 正能量 |
| 心灵 | 灵能伤害 |

## 三、状态效果（Conditions）

| 目盲（Blinded） | 攻击劣势，被攻击优势 |

| 恐慌（Frightened） | 攻击劣势，不能靠近恐惧源 |
| 擒抱（Grappled） | 速度为0 |

| 隐形（Invisible） | 攻击优势，被攻击劣势 |

| 石化（Petrified） | 变成石头 |

| 倒地（Prone） | 爬行，近战攻击劣势 |

| 昏迷（Unconscious） | 失能+倒地+不能移动 |

## 五、魔法体系

### 5.1 法术等级（Spell Levels）

- 戏法（Cantrip）— 0环，无限使用
- 1环~9环 — 需要法术位
- 魔法船魔舵消耗所有法术位来驱动船只

## 六、对卡牌冒险者的设计启示

### 6.1 可转化为卡牌的系统
- **攻击检定** → 攻击卡牌，掷骰判定
- **伤害类型** → 卡牌属性标签（火焰/冷冻/心灵等）
- **状态效果** → 状态卡牌（S-系列）
- **职业特色** → 职业卡牌（P-系列）
- **法术** → 法术卡牌/技能卡牌

### 6.2 数值映射建议
- d20 攻击检定 → 简化为卡牌攻击力 vs 防御力
- AC 系统 → 护甲卡牌 + 护盾状态
- 生命值 → HP 系统（已有基础）

### 6.3 职业设计方向
- 每个职业提供独特的**起始卡组**
- 职业决定可用卡牌类型
- 升级 = 解锁新卡牌/提升卡牌稀有度
