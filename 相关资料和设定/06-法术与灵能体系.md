# 06 — 法术与灵能体系

> 本文档整理DND法术体系与灵能（Psionics）体系，为卡牌冒险者的技能/法术卡牌设计提供参考。
> 来源：5E全职业法术卡、扩展灵能手册、5E不全书。

## 一、法术体系概述

### 1.1 法术等级与卡牌适配

| 法术等级 | 强度 | 建议卡牌稀有度 |
|----------|------|---------------|
| 戏法（Cantrip） | 基础 | 普通（Common） |
| 1-2环 | 初级 | 普通-罕见 |
| 3-4环 | 中级 | 罕见-稀有 |
| 5-6环 | 高级 | 稀有-史诗 |
| 7-8环 | 传奇 | 史诗 |
| 9环 | 神话 | 传说（Legendary） |

### 1.2 魔法学派（8大学派）

| 学派 | 代表法术 | 卡牌效果方向 |
|------|----------|-------------|
| 防护系 | 法师护甲、护盾术 | 护盾/防御增益 |
| 咒法系 | 传送术、召唤术 | 召唤/位移 |
| 预言系 | 侦测魔法、鉴识术 | 情报/侦查 |
| 附魔系 | 魅惑人类、睡眠术 | 控制/削弱 |

| 幻术系 | 隐形术、镜像术 | 迷惑/闪避 |
| 死灵系 | 亡灵召唤、疾病术 | 吸血/负面效果 |
| 变化系 | 变巨术、飞行术 | 属性增强/变形 |

## 三、灵能体系（Psionics）

### 3.1 灵能基础

来源：扩展灵能手册（Expanded Psionics Handbook, 3.5E）

> "心灵异能就是开发心灵潜能的艺术。一个灵能角色被赐予了这种天生的力量。"

**灵能 vs 法术的核心区别：**

| 方面 | 法术 | 灵能 |
|------|------|------|
| 资源 | 法术位 | 灵能点（Power Points） |
| 使用 | 每环固定次数 | 消耗灵能点，灵活分配 |
| 展现 | 言语/姿势/材料 | 心灵展现（Display） |
| 来源 | 学习/神赐 | 内在心灵力量 |
| 强化 | 不可 | 可消耗更多灵能点增幅 |

### 3.2 灵能职业

| 职业 | 说明 |
|------|------|
| 心灵术士（Psion） | 灵能版法师，专精心灵学科 |
| 心灵武士（Psychic Warrior） | 灵能与战斗结合 |
| 魂刃者（Soulknife） | 用意念创造心灵之刃 |
| 狂念者（Wilder） | 情感驱动的灵能者，爆发强但不稳定 |

### 3.3 灵能学科（Disciplines）

| 学科 | 说明 |
|------|------|
| 心灵预言（Clairsentience） | 探知、预知 |
| 心灵创造（Metacreativity） | 创造星质物体 |
| 心灵转化（Psychokinesis） | 意念移动物体/能量 |
| 心灵传送（Psychoportation） | 心灵传送、时间操纵 |
| 心灵附魔（Telepathy） | 读心、心灵控制 |
| 心灵自塑（Psychometabolism） | 身体变化、自我增强 |

### 3.4 灵能种族

| 种族 | 特征 |
|------|------|

## 四、对卡牌冒险者的设计启示

### 4.1 法术卡牌化
- 每张法术卡牌 = 一个法术（伤害/治疗/控制/增益）
- 法术等级 → 卡牌稀有度
- 法术学派 → 卡牌标签
- 灵能点 → 能量系统

### 4.2 灵能系统的独特价值
- 灵能点灵活分配 → 资源管理卡牌机制
- 灵能增幅 → 消耗额外能量提升效果
- 心灵展现 → 无需材料/言语，适合太空环境

### 4.3 星界专属法术
- 星界投影 → 特殊机制卡牌
- 异界传送 → 关卡切换
- 放逐术 → 移除敌人
