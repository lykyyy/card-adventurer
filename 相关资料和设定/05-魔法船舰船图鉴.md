# 05 — 魔法船舰船图鉴

> 本文档整理魔法船设定中的舰船类型、属性体系与船载武装。
> 来源：魔法船卷二《神秘太空百科》、魔法船译名表。

---

## 一、魔法船属性体系

### 1.1 舰船属性

| 属性 | 英文 | 说明 |
|------|------|------|
| 建造者 | Builder | 种族或势力 |
| 主要驾驶者 | Primary Helmsman | 通常由施法者驱动 |
| 吨位（Tonnage / T） | Tonnage | 船的规模，影响气囊大小和载货量 |
| 船体值（Hull Points / HP） | Hull Points | 船的耐久度 |
| 船员（Crew） | Crew | 最低/最高船员数 |
| 机动性（Maneuverability / MC） | Maneuver Class | A（最佳）到 G（最差） |
| 着陆能力 | Landing | 陆地/水面/仅太空 |
| 防护级别（Armor Rating / AR） | Armor Rating | 船的防御能力 |
| 豁免（Saving Throws） | Saves | 对抗特殊效果的豁免 |
| 动力能源（Power Source） | Power Type | 魔舵类型 |
| 战术速度（SR） | Ship's Rating | 战斗中移动速度 |
| 载货量（Cargo） | Cargo Capacity | 吨位 |
| 船长/船宽 | Length/Beam | 尺寸 |

### 1.2 机动性等级（Maneuverability Class）

| 等级 | 说明 |
|------|------|
| A | 极佳，可任意转向 |
| B | 优秀 |
| C | 良好 |
| D | 一般 |
| E | 笨拙 |
| F | 极差 |
| G | 几乎无法操控 |

## 五、对卡牌冒险者的设计启示

### 5.1 舰船系统化
- 将舰船属性转化为卡牌数据
- 吨位 → 卡牌品质/稀有度
- 船体值 → HP
- 机动性 → 先攻值/行动点数

### 5.2 舰船卡牌类型
- **舰船本体卡**：核心船只卡牌
- **魔舵卡**：动力系统
- **武器卡**：船载武装
- **船员卡**：NPC船员
- **升级卡**：舰船改造

### 5.3 参考数值范围
- 小型船：10-30T，HP 20-40
- 中型船：30-60T，HP 40-80
- 大型船：60-100T，HP 80-120
- 传奇船：100T+，HP 120+
