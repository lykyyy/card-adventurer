# 09 — 角色构筑详解

> 本文档详细提取DND 5E玩家手册中角色创建的全流程，为卡牌冒险者的角色系统设计提供完整参考。
> 来源：5E PHB 第1章（一步步创建角色）、第2章（种族）、第3章（职业）、第4章（个性与背景）、第5章（装备）、第6章（自定义选项）。

---

## 一、角色创建流程（PHB 第1章）

### 1.1 创建角色的标准步骤

| 步骤 | 内容 | 决策点 |
|------|------|--------|
| 1 | 选择种族 | 9个基础种族可选 |
| 2 | 选择职业 | 12个基础职业可选 |
| 3 | 确定属性值 | 掷骰法/标准数组/购点法 |
| 4 | 描述角色 | 阵营、理想、牵绊、缺点 |
| 5 | 选择背景 | 13个背景，提供技能和特性 |
| 6 | 选择装备 | 起始装备包或购金自选 |
| 7 | 集合数据 | 计算AC、HP、攻击加值等 |

### 1.2 属性值生成方法

| 方法 | 说明 |
|------|------|
| 掷骰法 | 4d6取最高3个，重复6次，自由分配 |
| 标准数组 | 15, 14, 13, 12, 10, 8 自由分配 |
| 购点法 | 27点购点池，所有属性起始8，最高可购至15 |

### 1.3 等级提升（Level Up）

- 经验值（XP）累积到阈值后升级
- 升级获得：新生命骰 + 体质调整值HP
- 职业特性随等级逐步解锁
- 第4/8/12/16/19级获得**属性值提升**（ASI）：+2单项或+1双项，上限20
- 熟练加值随等级自动提升

### 1.4 游戏四阶段（Tiers of Play）

| 阶段 | 等级 | 定位 |
|------|------|------|
| 第一阶段 | 1-4级 | 新手冒险者，本地威胁 |
| 第二阶段 | 5-10级 | 独当一面，区域性威胁 |
| 第三阶段 | 11-16级 | 领域大师，王国级威胁 |
| 第四阶段 | 17-20级 | 传奇英雄，世界/多元宇宙级威胁 |

### 3.2 职业核心特征详解

#### 野蛮人 — 狂暴 Rage
- 每日次数：2（1级）→ 6（20级）
- 效果：力量检定和力量豁免优势、近战伤害+2~+4
- 限制：不能穿重甲、不能施法/专注
- 子职业：狂战士（Berserker）、图腾武士（Totem Warrior）

#### 战士 — 动作如潮 Action Surge
- 2级起可用，每短休1次（17级2次）
- 效果：本回合额外获得1个动作
- 战斗风格：箭术、防御、对决、巨武器战斗、守护、双武器战斗
- 子职业：勇士（Champion）、战斗大师（Battle Master）、奥法骑士（Eldritch Knight）

#### 游荡者 — 偷袭 Sneak Attack
- 条件：攻击有优势，或目标5尺内有友方
- 伤害：1d6（1级）→ 10d6（20级），每奇数级+1d6
- 子职业：盗贼（Thief）、刺客（Assassin）、诡术师（Arcane Trickster）

#### 法师 — 奥术传承 Arcane Tradition
- 2级选择学派，抄写对应学派法术费用减半
- 8大学派：防护/咒法/预言/附魔/塑能/幻术/死灵/变化
- 法术书机制：起始6个1环法术，每级+2个法术

#### 邪术师 — 契约魔法 Pact Magic
- 法术位极少（1级1个→20级4个），但短休恢复
- 所有法术位自动升到最高环
- 魔能祈唤：永久被动能力（如魔能爆+CHA伤害）
- 宗主：魔君（Fiend）、旧日支配者（Great Old One）、精类（Archfey）

## 四、技能体系（PHB 第7章）

### 4.1 十八项技能与对应属性

| 属性 | 技能 |
|------|------|
| **力量 STR** | 运动（Athletics） |
| **敏捷 DEX** | 体操（Acrobatics）、巧手（Sleight of Hand）、隐匿（Stealth） |
| **智力 INT** | 奥秘（Arcana）、历史（History）、调查（Investigation）、自然（Nature）、宗教（Religion） |
| **感知 WIS** | 驯兽（Animal Handling）、洞悉（Insight）、医药（Medicine）、察觉（Perception）、生存（Survival） |
| **魅力 CHA** | 欺瞒（Deception）、威吓（Intimidation）、表演（Performance）、游说（Persuasion） |

### 4.2 技能熟练机制

- 熟练技能 = d20 + 属性调整值 + 熟练加值
- 非熟练技能 = d20 + 属性调整值
- 专精（Expertise）：游荡者/吟游诗人特性，熟练加值翻倍

| 专长 | 效果 |

## 八、对卡牌冒险者的设计启示

### 8.1 角色卡牌化
- **种族卡**：提供基础属性加值和种族特质
- **职业卡**：决定核心机制和可用卡牌池
- **背景卡**：提供额外技能和RP特性
- **属性卡**：6属性值转化为卡牌增益
- **装备卡**：护甲/武器/物品卡牌

### 8.2 简化建议
- 12职业 → 选取4-6个核心职业先行设计
- 9种族 → 选取与星界/太空相关的种族
- 18技能 → 简化为4-6个核心技能
- 升级系统 → 简化为卡牌获取/解锁机制

### 8.3 数值映射
- 熟练加值 → 卡牌等级/稀有度
- HP → 玩家生命值系统
- AC → 防御卡牌/护盾机制
- 偷袭/狂暴等 → 专属职业卡牌效果
