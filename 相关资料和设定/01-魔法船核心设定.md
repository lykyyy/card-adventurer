# 01 — 魔法船核心设定

> 来源：TSR 01049 魔法船战役设定集（Spelljammer: AD&D Adventures in Space, 1989）
> 作者：杰夫·格拉布（Jeff Grubb）
> 核心概念：用奇幻规则（魔法）替代科学规则（物理）的太空冒险

---

## 一、奇幻太空的基本法则

### 1.1 奇幻物理 vs 真实物理

魔法船宇宙的太空并非真空，而是遵循一套**自成一派的魔法物理法则**：

| 概念 | 真实太空 | 奇幻太空 |
|------|----------|----------|
| 空间介质 | 真空 | 可呼吸的气体海洋（气囊） |
| 航行方式 | 火箭推进 | 魔舵（Spelljammer Helm） |
| 重力 | 天体引力 | 重力平面（Gravity Plane） |
| 光与热 | 恒星核聚变 | 魔法光源/神火巨碗 |
| 星系边界 | 无限扩张 | 晶壁球（Crystal Sphere） |

> "这是魔法，并且它自成一派（it knows it's magic）。" — 杰夫·格拉布

### 1.2 晶壁系（Crystal Spheres）

- **晶壁球**：每个DND战役世界（如费伦、克莱恩、灰鹰）都被包裹在一个巨大的**晶壁球**中
- **晶壁**：晶壁球的边界，是一种不可见的魔法屏障
- **晶壁系**：整个晶壁球及其内部所有天体的总称
- 每个晶壁系内可以有独立的物理法则和星座排列
- 不同晶壁系之间通过**燃素海**（Phlogiston）连接

### 1.3 燃素海（Phlogiston）

- 又称：**彩虹色的海洋**（Rainbow Ocean）、**媒介**（Medium）
- 特性：极度易燃，任何明火或火花都会引发爆炸
- 在燃素海中**无法使用火系法术**
- 在燃素海中**无法进入任何位面**（外层位面、星界等均不可达）
- 燃素之潮（Flow）：燃素海中的河流，魔法船可借其快速航行

### 1.4 气囊与重力

- **气囊（Air Envelope）**：任何进入太空的物体都会携带一层可呼吸的空气
- 船只越大，气囊越厚，空气储备越久
- **重力平面（Gravity Plane）**：每艘魔法船都有自身的重力平面
  - 船员可以在甲板上正常行走
  - 船只翻覆时，重力方向同步翻转
  - 两艘船靠近时，重力平面会相互作用

## 二、魔法船航行系统

### 2.1 魔舵（Spelljammer Helm）

魔法船的核心动力装置，由**施法者**坐在魔舵上提供魔力驱动。

| 属性 | 说明 |
|------|------|
| 驱动者 | 施法者（法师/牧师/术士等） |
| 消耗 | 驱动者当日的所有法术位 |
| 速度 | 取决于驱动者的施法者等级 |
| 战术速度 | 六角格移动（战斗中） |
| 航行速度 | 星系间航行（百万英里/天） |

### 2.2 航行速度体系

- **战术速度（Tactical Speed / SR）**：战斗中使用的速度，以六角格/轮计算
- **航行速度（Spelljamming Speed）**：星系内航行，100万英里/天起步
- **燃素速度**：在燃素海中沿燃素之潮航行，速度取决于潮汐强度

### 2.3 着陆能力

魔法船可分为：
- **陆地着陆**：可在行星表面着陆
- **水面着陆**：可在水面降落
- **仅太空停泊**：无法进入大气层

## 三、魔法船社会与势力

### 3.1 种族与派系

| 势力 | 说明 |
|------|------|
| 精灵海军（Elven Navy） | 最强大的太空军事力量，守护精灵世界 |
| 秘法商族（Arcane） | 神秘的蓝色巨人种族，垄断魔舵贸易 |
| 夺心魔（Mind Flayers） | 灵吸怪，螺壳舰的使用者 |
| 眼魔（Beholders） | 多种眼魔船只的拥有者 |
| 人类帝国 | 分散的太空人类势力 |
| 矮人 | 开采小行星的矿业种族 |
| 地精 | 太空海盗与拾荒者 |

### 3.2 非人战争（Unhuman Wars）

- 精灵海军与各类怪物种族（地精、兽人等）之间的大规模太空战争
- 精灵获胜，但也付出了巨大代价
- 战后大量废弃的魔法船和武器散布在太空各处

### 3.3 布拉之岩（Rock of Bral）

- 一座建在类星体上的太空城市
- 多种族混居的贸易港口和冒险者基地
- 类似"太空中的自由港"

## 四、航天士与冒险者

### 4.1 航天士（Voyager）/ 宇航家（Spacefarer）

- **地表人（Groundling）**：从未离开过行星表面的生物
- **航天士**：在太空中航行过的冒险者
- 航天士对太空知识有额外熟练加成

### 4.2 太空冒险要素

| 要素 | 说明 |
|------|------|
| 太空海盗 | 劫掠商船的海盗舰队 |
| 废弃船 | 漂浮在太空中的无主魔法船 |
| 死魔法区 | 魔法完全失效的太空区域（马尾藻区/Sargassos） |
| 黑暗宙域 | 远离恒星的极寒黑暗区域 |
| 异次元虫洞 | 连接不同晶壁系的虫洞 |
| 小行星带 | 矮人矿业区、海盗藏身处 |

## 五、对卡牌冒险者的设计启示

### 5.1 可直接借用的设定
- 魔法船作为"移动基地/家园"的概念
- 晶壁系之间的航行作为"关卡切换"机制
- 气囊/空气储备作为资源管理要素
- 魔舵驱动者等级决定航行范围

### 5.2 需适配的设定
- 将AD&D 2E规则转换为5E兼容数值
- 将燃素海替换为星界（Astral Plane）航行（5E Spelljammer设定）
- 简化舰船战斗为卡牌战斗机制

### 5.3 核心设计约束
- 太空船必须作为核心卡牌/装备系统的一部分
- 所有太空遭遇统一为卡牌格式
- 保留"奇幻太空"的反科学浪漫感
