# 02 — 星界与位面指南

> 卡牌冒险者的核心场景：在星界（Astral Plane）中驾驶太空船穿越不同位面与晶壁系。
> 本文档整合DND位面体系与魔法船宇宙观，为游戏世界构建提供设定基础。

---

## 一、DND 位面体系总览

### 1.1 大轮（Great Wheel）宇宙模型

DND标准宇宙学将存在分为以下层级：

| 层级 | 名称 | 说明 |
|------|------|------|
| 物质位面 | Material Plane | 凡人居住的物理世界，包含无数晶壁系 |
| 星界 | Astral Plane | 连接物质位面与外层位面的银色虚空 |
| 以太位面 | Ethereal Plane | 连接物质位面与内层位面的迷雾领域 |
| 内层位面 | Inner Planes | 元素位面（火/水/土/气）+ 能量位面 |
| 外层位面 | Outer Planes | 神祇与信仰的领域，基于九大阵营排列 |

### 1.2 魔法船宇宙的位面特殊性

在魔法船设定中：
- **燃素海**替代了星界作为晶壁系之间的连接介质
- 在燃素海中**无法触及任何位面**
- 只有进入晶壁系内部后，才能使用位面旅行法术
- 5E版 Spelljammer 将燃素海重设为**星界**，使太空航行 = 星界航行

## 二、星界（Astral Plane）详解

### 2.1 星界的基本特征

| 特征 | 描述 |
|------|------|
| 外观 | 银色虚空，满天星点 |
| 重力 | 无客观重力，主观方向（想往哪走就往哪走） |
| 时间 | 时间不流动——不会饥饿、不会衰老、不会自然愈合 |
| 移动 | 智力决定移动速度（智力×3尺/轮） |
| 呼吸 | 不需要呼吸 |
| 物质 | 万物皆由思想构成，高智力者可凭意志塑形 |

### 2.2 星界中的存在

| 存在 | 说明 |
|------|------|
| 星界旅行者 | 使用星界投影（Astral Projection）法术的施法者 |
| 吉斯洋基人（Githyanki） | 星界中的主要文明种族，在星界中建立城市 |
| 星界巨舰（Astral Dreadnought） | 星界中的顶级掠食者 |
| 神祇尸体 | 死去神祇的石质遗骸漂浮在星界中 |
| 颜色池（Color Pools） | 通往各外层位面的传送门 |
| 银线（Silver Cord） | 连接星界投影者与其肉体的生命线 |

### 2.3 星界航行的卡牌冒险者适配

对于本项目：
- 魔法船在星界中航行（非燃素海）
- 星界中时间不流动 → 可以作为"安全区/基地"概念
- 颜色池 → 通往不同"关卡/世界"的入口
- 星界巨舰 → 可作为Boss级敌人
- 吉斯洋基人 → 可作为派系/交易对象/敌人

## 三、外层位面（Outer Planes）

### 3.1 九大阵营位面

| 阵营 | 位面名称 | 特性 |
|------|----------|------|
| 守序善良 LG | 天堂山（Mount Celestia） | 七层圣山，天使与圣骑士 |
| 中立善良 NG | 极乐境（Elysium） | 永恒的安宁与满足 |
| 混乱善良 CG | 奔放之野（Arborea） | 精灵神系所在，永恒的狂欢 |
| 守序中立 LN | 机械境（Mechanus） | 绝对的秩序，齿轮运转 |
| 绝对中立 N | 外域（Outlands） | 众门之城印记城所在 |
| 混乱中立 CN | 混沌海（Limbo） | 纯粹的混沌，吉斯泽雷人居住 |
| 守序邪恶 LE | 九层地狱（Baator） | 魔鬼的领域 |
| 中立邪恶 NE | 灰色荒野（Hades） | 尤格罗斯魔的领域 |
| 混乱邪恶 CE | 无底深渊（Abyss） | 恶魔的领域，无限层数 |

### 3.2 异度风景（Planescape）与印记城

- **印记城（Sigil）**：位于外域中心的环形城市，由痛苦女士统治
- 印记城中有通往所有位面的传送门
- 是多元宇宙的十字路口，各种族交汇之地
- **派系（Factions）**：印记城中的15个哲学派系，各自控制不同领域

## 四、内层位面与元素

### 4.1 元素位面

| 位面 | 特性 |
|------|------|
| 火元素位面 | 永恒的火焰，火巨灵与火元素的领域 |
| 水元素位面 | 无尽海洋，水巨灵与水元素 |
| 土元素位面 | 固态岩石，土巨灵与土元素 |
| 气元素位面 | 无尽天空，风巨灵与气元素 |

### 4.2 能量位面

- **正能量位面**：纯粹的生命能量，过度暴露会爆体
- **负能量位面**：纯粹的死亡能量，不死生物的能量来源

## 五、晶壁系与DND世界

### 5.1 主要晶壁系

| 晶壁系 | 战役设定 | 标志性特征 |
|--------|----------|-----------|
| 国度天宇（Realmspace） | 被遗忘的国度 | 费伦大陆，伊尔明斯特 |
| 克莱恩天宇（Krynnspace） | 龙枪 | 克莱恩，索兰尼亚骑士 |
| 灰鹰天宇（Greyspace） | 灰鹰 | 奥斯，魔邓肯 |
| 星际天宇 | 魔法船原生 | 布拉之岩 |

### 5.2 晶壁系内部结构

每个晶壁系通常包含：
- 一颗或多颗**主要天体**（行星/世界）
- 若干**恒星**（魔法光源或神火）
- **小行星带**（残渣/Debris）
- 外层**晶壁**（边界）

## 六、对卡牌冒险者的设计启示

### 6.1 世界结构建议
- 将游戏关卡设计为不同的**晶壁系/位面**
- 魔法船在**星界**中航行（移动基地）
- 每个晶壁系 = 一个**章节/区域**
- 颜色池/传送门 = 关卡入口

### 6.2 敌人与势力
- 星界原生：吉斯洋基人、星界巨舰
- 外层位面：恶魔、魔鬼、天使
- 魔法船势力：精灵海军、夺心魔、太空海盗

### 6.3 卡牌设计方向
- 位面卡牌：代表不同位面的特殊效果
- 传送门卡牌：切换场景/关卡
- 星界事件卡牌：星界中的随机遭遇
